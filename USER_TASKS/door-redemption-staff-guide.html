Working the Door

How to check & redeem the "2 free shots" codes · La Tribu · 9 July 2026

The short version: Customers who signed up online got a unique code by email. At the bar, you open one web page, type their code, and it tells you in big letters: GREEN = give 2 shots, RED = don't. Each code only works once.

What you need

  • A phone (or tablet) with internet.
  • This web page open:
    latribu.co.uk/redeem.html
  • Tonight's staff password (the organiser will give you this):

Tip: open the page in your phone browser and add it to your home screen so it's one tap to reopen.

One-time setup (start of shift)

  1. Open latribu.co.uk/redeem.html in your phone browser.
  2. You'll see a Staff password box. Type the password the organiser gave you and tap Unlock.
  3. That's it — you're in. You won't need to type the password again unless you close the browser tab.
If it says "Staff password rejected", the password is wrong or hasn't been set yet — check with the organiser. Don't let anyone in without it.

Redeeming a customer's code

  1. Ask the customer to show their code (it's in their welcome email, looks like ABCD-EFGH-JKLM — 12 letters/numbers).
  2. Type it into the Customer code box. The dashes are added automatically — just type the letters and numbers. It doesn't matter if you use CAPITALS or lowercase.
  3. Tap Redeem 2 free shots.
  4. Read the colour of the result and act on it (see below).
  5. The box clears itself, ready for the next customer.

What the result means

✓ GREEN
Valid

Pour the 2 shots. The code is good and has now been marked as used so it can't be used again.

✕ RED
Already used

Do not pour. This code was already redeemed earlier — politely let them know it's already been claimed.

✕ RED
Not valid

Do not pour. No such code exists — likely a typo. Double-check the spelling with the customer and try again.

⚠ AMBER
Problem

Either the password was rejected (you'll be sent back to the password screen — re-enter it) or there's a connection issue (check signal and tap Redeem again). No shots until you get a green.

Golden rules

  • Only pour on GREEN. Any red or amber = no free shots.
  • One code = one person = 2 shots, once. The system stops a code being reused — trust it.
  • Over-18s only. Normal age checks still apply, code or no code.
  • If a customer insists their valid code shows red, take their name/email and send them to the organiser — don't override.

Quick answers

They don't have the email / lost the code?
No code, no free shots. Send them to the organiser if they're sure they signed up.
Phone died / browser closed?
Reopen latribu.co.uk/redeem.html and type the staff password again. Codes already redeemed stay redeemed.
I typed it wrong and it went red?
No harm — a wrong/not-found code changes nothing. Just retype the correct one.
Can I redeem from more than one phone?
Yes. Several staff can use the page at once with the same password.
End of shift?
Tap "Lock / change password" to clear the password from the device — especially on a shared phone.
For the organiser: the staff password is the STAFF_SECRET you set in Supabase (Edge Functions → Manage secrets). Share it verbally or in writing with door staff at the start of the night; don't write it on this sheet if you'll be handing the sheet around. To rotate it, change the secret in Supabase and tell staff the new one.
